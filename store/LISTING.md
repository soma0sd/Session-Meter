## 한국어

- 제품명 · 세션미터
- 분류 · 유틸리티 및 도구
- 설명 · 세션미터는 Claude, Codex, Gemini, Antigravity IDE의 구독 한도와 초기화 시각을 Windows 트레이, 데스크톱 위젯, 통계 창에서 표시합니다. 위젯은 서비스별로 표시하거나 하나의 격자에 배치할 수 있습니다. 통계에서 사용 이력을 조회하고, 정해 둔 사용률에 도달하면 Windows 알림을 받을 수 있습니다.

## English

- Product name · SessionMeter
- Category · Utilities & tools
- Description · SessionMeter displays subscription quotas and reset times for Claude, Codex, Gemini, and Antigravity IDE. Open a widget for each service or arrange multiple services in one desktop grid. The statistics window shows usage history, and Windows notifications alert you at selected usage thresholds.
- Connections · Connect your own Claude, Codex, or Gemini account to view its quota. Antigravity monitoring uses the local IDE or the installed agy CLI. This is an independent app and uses unofficial service integrations.
