세션미터 개인정보 처리방침

처리하는 정보

세션미터는 사용자가 연결한 Claude, Codex, Gemini 계정의 구독 한도와 초기화 시각을 조회합니다. 서비스가 제공하는 계정 이름, 이메일 주소, 요금제를 설정 또는 통계 창에 표시할 수 있습니다. Antigravity IDE의 사용량은 로컬 IDE에서 읽으며, 연결할 수 없으면 설치된 agy CLI에 사용량 조회를 요청합니다.

저장 및 삭제

설정과 사용 이력은 Windows 사용자 계정의 앱 데이터 폴더에 저장합니다. 사용 이력은 기본 30일 동안 유지됩니다. 앱이 보관하는 서비스 세션 파일은 Windows DPAPI로 현재 사용자 계정에 맞춰 암호화합니다. 연결을 해제하면 해당 서비스의 저장된 세션을 제거합니다. 남은 설정과 이력은 앱을 종료한 뒤 해당 앱 데이터 폴더에서 삭제할 수 있습니다.

네트워크 통신

로그인과 사용량 조회는 해당 서비스에 연결합니다. 변경 이력은 GitHub에서 읽을 수 있으며, GitHub 배포판은 GitHub에 새 버전을 확인합니다. Microsoft Store판 업데이트는 Microsoft Store가 관리합니다. 앱 개발자는 분석 도구를 사용하거나 구독 사용량, 계정 정보, 사용 이력을 수집하지 않습니다.

문의

앱의 데이터 처리에 관한 문의는 프로젝트 문의 게시판을 이용해 주십시오. 공개 게시물에 계정 정보나 세션 파일을 첨부하지 마십시오.

SessionMeter Privacy Policy

Effective November 24, 2026

Data the app processes

SessionMeter retrieves subscription limits and reset times for Claude, Codex, and Gemini accounts you connect. It may display the account name, email address, and plan provided by a service. SessionMeter reads Antigravity usage from the local IDE or requests usage data from the installed agy CLI when the IDE is unavailable.

Storage and deletion

SessionMeter stores settings and usage history in your Windows user profile. Usage history is kept for 30 days by default. Windows DPAPI encrypts saved service session files for the current Windows user. Signing out of a service removes its saved session. You can delete remaining settings and history from the app data folder after closing the app.

Network activity

SessionMeter connects to each linked service for sign-in and quota retrieval. It can read release notes from GitHub. The GitHub edition checks GitHub for updates, and Microsoft Store manages updates for its edition. The developer does not use analytics or collect subscription usage, account details, or usage history from the app.

Contact

Use the project issue tracker for questions about data handling. Keep account information and session files out of public posts.
