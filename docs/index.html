소개

SessionMeter는 Claude, Codex(ChatGPT 구독), Gemini, Antigravity IDE의 사용량을 시스템 트레이 아이콘, 데스크톱 위젯, 통계 창으로 보여 주는 데스크톱 애플리케이션입니다. 로그인한 (또는 연동된) 서비스마다 제공되는 5시간·주간 등의 남은 사용량과 초기화까지 남은 시간을 한눈에 확인할 수 있습니다. Tauri v2로 제작된 오픈소스(MIT) 프로그램입니다.

비공식 도구이며 이용약관에 유의해야 합니다. Claude·Codex·Gemini는 로그인된 본인 세션을 이용해 각 서비스의 사용량 페이지와 동일한 데이터를 가져오는 방식입니다. 공식/공개 API가 아니며 해당 서비스의 API 키를 사용하지 않습니다. 각 서비스의 약관은 봇·스크립트 등 자동 수단의 접근을 제한하므로 이 방식은 약관에 어긋날 수 있고 계정 제재 위험이 있습니다. 반드시 Anthropic 약관과 OpenAI 이용약관, Google 약관을 확인하고 본인 책임으로 사용하십시오. Antigravity IDE는 원격 웹 페이지가 아니라 본인 PC에서 실행 중인 IDE가 제공하는 로컬(loopback) API를 사용하므로 원격 웹 서비스와 위험 성격이 다르지만, 문서화되지 않은 인터페이스이므로 IDE 업데이트에 따라 동작이 바뀌거나 중단될 수 있습니다. 본 프로그램은 Anthropic·OpenAI·Google·Antigravity IDE 개발사와 무관하며, "Claude"는 Anthropic, PBC의, "Codex"와 "ChatGPT"는 OpenAI의, "Gemini"는 Google LLC의, "Antigravity"는 해당 개발사의 상표입니다.

설치

릴리스 페이지에서 Windows 설치 프로그램(SessionMeter_x.y.z_x64-setup.exe)을 내려받아 실행합니다. Windows 10/11에서 동작하며 WebView2 런타임이 필요합니다(최신 Windows에는 기본 포함). 업데이트는 새 설치 프로그램을 실행하면 기존 설정과 로그인 세션이 유지된 채 덮어 설치됩니다. 앱 안에서 새 버전이 확인되면 위젯과 트레이 메뉴에 설치 버튼이 나타나며, 눌러서 바로 업데이트할 수 있습니다.

서비스 로그인

트레이 아이콘을 우클릭해 설정을 열면 계정 목록에서 서비스별로 로그인·로그아웃할 수 있습니다. 로그인한 서비스만 트레이 툴팁·위젯·통계에 나타납니다.

Claude

앱 안에서 claude.ai 로그인 창이 열리며, 로그인을 완료하면 세션이 자동으로 저장됩니다. 세션은 OS 애플리케이션 데이터 폴더의 사용자별 파일에 저장되고, Windows에서는 DPAPI(사용자 범위)로 암호화되어 다른 사용자·오프라인 디스크·복사된 백업에서 복호화할 수 없습니다.

Codex

설정에서 Codex 로그인을 선택하면 앱 안에서 ChatGPT 로그인 창이 열립니다. 로그인 후 `chatgpt.com` 세션을 검증해 저장하고, Codex 구독의 주간 한도를 위젯·통계에 표시합니다. `primary_window`와 `secondary_window` 중 `limit_window_seconds`가 `604800`인 창만 사용하며, 5시간 세션, OpenAI API 토큰 사용량·비용과 추가 모델별 한도는 표시하지 않습니다.

Codex 사용량 조회는 비공개 `chatgpt.com` 엔드포인트에 의존합니다. 로그인 쿠키 또는 응답 구조가 바뀌면 세션이 만료되거나 조회가 실패할 수 있으며, 이 경우 설정에서 다시 로그인합니다.

Gemini

Gemini 로그인은 별도의 프로세스로 격리된 창에서 진행됩니다. 이렇게 하면 Google 로그인 페이지에 문제가 있어도 앱 본체(트레이·위젯·다른 서비스)는 영향을 받지 않습니다. 창에서 본인 Google 계정으로 로그인하면 창이 자동으로 닫히고 사용량이 표시됩니다.

Gemini는 공식 API가 없어 gemini.google.com의 사용량 표시를 그대로 읽어오는 실험적 기능입니다. Google이 임베드 브라우저 로그인을 정책적으로 제한하므로, 로그인이 실패하거나 페이지 구조 변경으로 수치가 달라질 수 있습니다.

Antigravity IDE

Antigravity IDE는 로그인이 따로 필요 없습니다. 로컬에 설치된 Antigravity IDE가 실행 중이면 SessionMeter가 자동으로 감지해 연동하고, 설정 창 계정 목록에 실행 중 상태로 표시됩니다. IDE를 종료하면 연동도 함께 해제됩니다.

데스크톱 위젯

위젯은 테두리가 없고 작업 표시줄에 나타나지 않는 떠 있는 창으로, 각 항목의 남은 사용량과 초기화까지 남은 시간을 보여 줍니다. 표시 내용에 맞춰 창 크기가 자동으로 맞춰지며, 로그인한 서비스마다 독립된 위젯 창이 뜨고 제목표시줄에 서비스 이름이 표시됩니다.

컴팩트 위젯의 상단 더보기 메뉴는 위젯 패널 위에 팝오버로 열립니다. 메뉴를 열거나 닫아도 사용량 본문과 도킹된 이웃 위젯의 위치는 바뀌지 않습니다.

아래 두 지표 예시는 Claude 위젯 기준입니다. Codex 위젯은 `limit_window_seconds`가 `604800`인 주간 지표 하나만 표시하며 5시간 세션을 표시하지 않습니다.

  • 통계·설정·스타일 바로가기: 상단 아이콘으로 통계 창, 설정 창, 위젯 스타일 창을 엽니다. 폭이 좁으면 아이콘이 점 세 개 메뉴로 접힙니다.
  • 항상 위 고정: 핀 아이콘으로 켜고 끕니다. 켜면 다른 창 위에 항상 표시됩니다.
  • 위치 잠금: 자물쇠 아이콘으로 켜고 끕니다. 잠금 해제 상태에서 위젯을 끌어 원하는 위치로 옮길 수 있으며, 옮긴 위치는 재부팅 후에도 복원됩니다.
  • 투명도: 위젯 스타일 창의 투명도 슬라이더로 조절합니다.

위젯 스타일

트레이 메뉴 또는 위젯 상단의 팔레트 아이콘으로 위젯 스타일 창을 엽니다. 다섯 가지 그래픽 컨셉을 각각 상세·컴팩트 두 형태로, 총 10종 중에서 서비스별로 선택합니다. 실시간 미리보기와 표시 토글(남은 사용량 / 사용한 사용량)을 제공합니다.

위젯 지표 색상은 서비스에 맞춰 표시됩니다(예: Claude 코럴, Codex 그린, Gemini 블루). 아래 갤러리는 앱의 실제 위젯 컴포넌트를 그대로 렌더한 것으로(스크린샷 아님, Claude 색상 · 남은 사용량 표시 기준 · 예시 값), 확대해도 선명합니다.

알림

사용량이 설정한 기준(기본 80%·95%)에 도달하거나 세션이 초기화될 때 데스크톱 알림을 보냅니다. 설정에서 이번 세션·주간 세션 각각의 기준과 초기화 알림을 켜고 끌 수 있습니다.

설치본에서는 알림 발신 주체가 SessionMeter로 표시됩니다. 개발 모드에서는 Windows 특성상 발신 주체가 다르게 보일 수 있습니다.

설정

  • 테마: 시스템 / 라이트 / 다크. 트레이 아이콘, 위젯, 통계, 메뉴에 모두 적용되며, 시스템 선택 시 OS 라이트/다크 전환을 실시간으로 따릅니다.
  • 언어: 자동(OS 언어) / 한국어 / English.
  • 갱신 주기: 1 / 5 / 10 / 15 / 30분.
  • 시작 시 실행: 로그인 시 자동 실행 등록.
  • 알림: 사용량 기준·초기화 알림.
  • 계정: Claude·Codex·Gemini는 로그인 상태와 로그인/로그아웃 버튼을 제공합니다. Claude·Gemini는 가능한 경우 이름·이메일을, Codex는 응답이 제공하는 ChatGPT 플랜 식별자를 함께 표시합니다. Antigravity는 로그인 개념이 없어 IDE 실행 여부에 따라 실행 중 상태만 표시됩니다.

위젯 관련 설정(스타일, 표시 기준, 투명도, 항상 위, 이동 잠금, 그리드 도킹)은 위젯 스타일 창에서 서비스별로 관리합니다.

문제 해결

  • 사용량이 표시되지 않음: 설정에서 해당 서비스의 로그인 상태를 확인하고, 필요하면 다시 로그인합니다.
  • 세션 만료: 서비스 세션이 만료되면 다시 로그인해야 합니다.
  • Gemini 로그인 화면이 뜨지 않거나 "안전하지 않은 브라우저" 안내가 나옴: Google이 임베드 로그인을 제한하는 경우입니다. 창을 닫고 잠시 후 다시 시도합니다. 로그인 창은 별도 프로세스라 실패해도 앱 본체는 계속 동작합니다.
  • Codex 사용량이 표시되지 않음: ChatGPT 세션이 만료되었거나 비공개 사용량 응답이 변경된 경우입니다. 설정에서 Codex를 로그아웃한 뒤 다시 로그인합니다. OpenAI API 사용량과 비용은 지원 대상이 아닙니다.
  • Antigravity가 "실행 중"으로 표시되지 않음: Antigravity IDE가 실제로 실행 중인지 확인합니다. IDE의 로그인 포트·인증 토큰은 재시작마다 바뀌므로 SessionMeter가 매번 다시 탐색하며, IDE를 새로 켰다면 다음 갱신 주기까지 잠시 기다립니다. 현재 Windows 에서만 지원됩니다.
  • 트레이 아이콘이 보이지 않음: Windows 작업 표시줄의 숨겨진 아이콘 영역(^)을 확인합니다.
  • 수치가 갱신되지 않음: 설정의 갱신 주기를 확인합니다. 갱신은 주기마다 자동으로 이루어집니다.
